# Dr. D. K. Mishra Clinic (डॉ. द. मिश्रा क्लिनिक)

Premium, trustworthy, responsive medical clinic website for **Dr. D. K. Mishra Clinic**, located in Hatia, Ranchi, Jharkhand.

## Features
- **Official Clinic Presence**: Clean, verified healthcare branding with Inter / Plus Jakarta Sans typography and deep navy/teal palette.
- **Top Bar Contract Compliant**: 3-zone header with single wordmark, clean links, and direct action triggers.
- **Appointment Booking System**: Date picker with past-date disabled, clinic-schedule aware, collision & double-booking prevention, form validation, and reference code generator.
- **Doctor Profile**: Professional doctor showcase for Dr. D. K. Mishra with support for verified credentials and real photo upload.
- **Medical Services**: Verified consultation offerings with patient preparation guidelines.
- **Patient Reviews**: 4.1/5 rating across 11 Google Reviews with verified link integration.
- **Contact & Map**: Click-to-call `08803509240`, Google Plus Code `8829+85`, day-by-day weekly consultation schedule.
- **Private Admin Dashboard**: Passcode-protected (`admin2026` or `08803509240`) management console for appointments, services, schedule, doctor profile, and reviews.
- **Netlify & GitHub Ready**: Preconfigured with `netlify.toml` and `public/_redirects` for 100% smooth Single Page Application (SPA) routing.

## 🚀 How to Push to GitHub

1. Open your terminal in this project folder:
```bash
git init
git add .
git commit -m "feat: complete Dr. D. K. Mishra Clinic website"
```

2. Create a new repository on [GitHub](https://github.com/new) (e.g. `dr-dk-mishra-clinic`).

3. Link and push to GitHub:
```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/dr-dk-mishra-clinic.git
git push -u origin main
```

## 🌐 How to Deploy to Netlify from GitHub

1. Log in to your [Netlify](https://app.netlify.com/) account.
2. Click **"Add new site"** -> **"Import an existing project"**.
3. Choose **GitHub** and authorize Netlify.
4. Select your repository: `dr-dk-mishra-clinic`.
5. Netlify will automatically detect the settings from `netlify.toml`:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
6. Click **"Deploy dr-dk-mishra-clinic"**.
7. In ~30-45 seconds, your site will be live with full HTTPS and custom domain support!
